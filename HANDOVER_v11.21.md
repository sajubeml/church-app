## 1. Release Highlights (v11.21)

### A. High-Fidelity Readable Smart Report Print Engine
- **Prior Issue:**
  - In Smart Report Studio, clicking "Export PDF / Print" routed the table directly to `exportTableToPDF('smartReportTable')`.
  - That function was originally designed for the massive 40-column Cash Book and Member Ledger grids, applying `zoom: 0.55`, `font-size: 8px !important;`, and `@page { size: A4 landscape; margin: 4mm 5mm; }`.
  - When printed or exported, the smart report appeared as a microscopic, squished, unreadable horizontal strip at the top of an A4 page.
- **The Resolution:**
  - Built a dedicated, intelligent printing engine for Smart Reports (`exportSmartReportPDF()`).
  - **Single Member Statements:** When filtered to a specific member, the engine automatically formats the document into the official, high-contrast **Member Contribution Statement & Receipt Summary** layout (identical to the layout generated by "Export All PDFs"):
    - St. Gregorios Church header with logo, address, and title.
    - 4-column Member Summary Card: Register No (`#128` or `#174`), Statement Date (`DD-MM-YYYY`), Member Name, Rt No. / Ref, Subscription Upto validity period, and Total Contributions.
    - Itemized Receipt Transactions & Contributions table with 11.5px/12px readable fonts, `#1A365D` headers, clean padding, and a bold blue summary row (`TOTAL MEMBER CONTRIBUTIONS`).
    - Formal verification footer: Date, Verified By: Trustee / Vicar, Authorized Signature & Seal.
  - **General & Summary Statements:** When filtered to All Members, Non-Members (NM), or summary grouping (Member Summary / Account Head Summary):
    - Full official church letterhead with logo.
    - Filter Criteria & KPI Summary card (Date range, flow type, account head, member filter, total entries, total cash, total bank, combined grand total).
    - Spacious, readable tables (11px font, alternating zebra shading, bold totals).

### B. Explanation and Solution for Landscape & Portrait Orientation
- **Why Orientation Was Previously Absent in Print Preview:**
  - When CSS `@page` contains an explicit orientation rule like `size: A4 landscape;`, Chromium browsers (Edge, Chrome, Opera, Android WebView) lock the orientation to the CSS declaration and **hide the "Layout: Portrait / Landscape" dropdown** from the print dialog sidebar.
- **The Solution:**
  - Added interactive in-app orientation buttons directly on the Print Preview navigation bar:
    - **`[ 📄 Portrait ]`**
    - **`[ 📑 Landscape ]`**
  - Clicking either button instantly updates the document width and the dynamic `@page` rule (`A4 portrait` or `A4 landscape`), giving the user immediate, effortless control before triggering system print.
  - Defaults single-member contribution statements to **Portrait** (fits cleanly on 1 sheet of A4 without spillover) and detailed transaction registers to **Landscape**.
